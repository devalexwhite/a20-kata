# August20 Programming Kata Solution

## Execution

To run this program, follow the following:

1. `git clone https://github.com/devalexwhite/a20-kata.git`
2. `cd a20-kata`
3. `npm i`
4. `npm run start -- -i inputs/input.txt -m 1`

The following CLI arguments are accepted:

|Argument|Short Form|Purpose|
|---|---|---|
|--input|-i|Relative path to a test input file|
|--mode|-m|Set to 1 for part 1 of the Kata, and 2 for part 2|

## Testing

Unit tests are found in `/tests`. To run tests, use the following command: `npm run test`.
